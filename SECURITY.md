# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Please [report vulnerabilities privately](https://github.com/jhkdlut/columnpilot/security/advisories/new) through GitHub's private vulnerability reporting feature, enabled for this repository. Do not include credentials, production endpoints, or sensitive data in a public issue.

Useful reports include the affected version or commit, reproduction steps, expected impact, and a minimal proof of concept.

See [the endpoint and request-limit review](docs/security-review.md) for the trust boundaries and regression coverage. A successful CodeQL workflow means analysis completed; open security findings still require review.
